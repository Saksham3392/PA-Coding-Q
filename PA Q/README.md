# ☕ Java Practice Compiler & Test Bench (120+ Challenges across 20 Topics)

**Live Web App:** https://javaprogrammingq.onrender.com

A production-grade, browser-based Java execution workbench built to bridge the gap between concept and code. It provides an automated, zero-setup test runner designed specifically for mastering arrays, strings, 2D matrices, recursion, graphs, trees, queues, stacks, searching, sorting, and competitive programming edge cases.

---

## 🚀 1. Quick Start (Run Locally)

Run the following commands in terminal / Command Prompt:

```cmd
python server.py
```
Or double-click `run.bat` on Windows.

---

### 🎯 What This Lab Solves
* **Zero Overhead:** No IDE configuration or local JDK switching required to practice core concepts.
* **Instant Assertion Engine:** High-speed Single-JVM test harness runs dynamic assertions against boundary inputs, hidden edge cases, and performance limits.
* **Algorithmic Muscle Memory:** 121 curated challenges structured across 20 topics from fundamental 1D arrays and strings to binary search trees, graph traversals, and dynamic matrices.
